Construye tu propio React

Reconstruye React desde cero, pieza a pieza: cada concepto por separado con un ejemplo diminuto, y después todo junto en un React que funciona en el navegador y crece con cada módulo.

intermedio1 de 24 lecciones9 minpublicado el 7 nov 2026

Empezar el cursoTodos los cursos

En este curso reconstruyo React desde cero: JSX, los fibers, el reconciliador, los hooks, los efectos, el contexto, los eventos, las lanes, el scheduler, Suspense y las API de React 19. Al final queda un React pequeño, mini-react, que renderiza componentes reales en el navegador, y un panel de DevTools que muestra cada una de sus piezas en acción.

Está pensado para ti si usas React todos los días y nunca has leído su código fuente. Sabes lo que hacen useState y useEffect; este curso trata de cómo lo hacen y de por qué las reglas que los rodean son las que son.

Cómo está organizado el curso

Nunca construyo todo de una vez. Hay tres tipos de lección:

  • Las lecciones aisladas enseñan un solo concepto, por separado, con un ejemplo diminuto propio. Lo que ese concepto necesite del resto de React lo simulo a mano, así que puedes entenderlo sin saber lo que viene después.
  • Las fusiones aisladas combinan dos de esas lecciones en un pequeño motor que sigue funcionando sin React alrededor. Hay dos: el motor de estado y el bucle de prioridades.
  • Los hitos parten del hito anterior, le conectan las piezas nuevas y terminan con un React que funciona en el navegador y hace estrictamente más que el anterior. Un hito solo escribe el código que une las piezas; las ideas ya se explicaron en las lecciones que llevan a él.

Cada módulo termina en un hito. El primero pinta un árbol estático, el siguiente lo actualiza, después llegan el estado, los efectos y el contexto, luego el render concurrente, Suspense y las API de React 19. El módulo final abre mini-react con sus DevTools, donde cada panel corresponde a una lección.

Lee el mapa de arriba abajo: ese es el orden de las lecciones. Las lecciones aisladas se pueden leer casi en cualquier orden, pero un hito necesita todo lo que apunta hacia él.
